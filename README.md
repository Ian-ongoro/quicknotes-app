How to Run the Project Locally

No build tools, bundlers, or server setups are required to run QuickNotes locally.

Clone the Repository:

git clone https://github.com/your-username/quicknotes-app.git


Navigate into the Project Folder:

cd quicknotes-app


Open in Browser:

Double-click the index.html file to launch it directly in your default web browser, or

Use VS Code's Live Server extension by right-clicking index.html and selecting Open with Live Server.
